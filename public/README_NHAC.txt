Hướng dẫn thêm nhạc MP3 khi đẩy code lên GitHub:

Đặt 2 file nhạc của bạn vào thư mục `public/` với đúng tên:
- public/bai1.mp3
- public/bai2.mp3

Trang web sẽ tự động phát `/bai1.mp3` khi chọn Bài 1 và `/bai2.mp3` khi chọn Bài 2, đồng thời quay đĩa nhạc và hiển thị lời bài hát ngay phía trên đĩa nhạc ở góc dưới bên trái.
Nếu chưa có file mp3 trong `public/`, trình phát vẫn tự động dùng giai điệu piano nhẹ nhàng và nút Chọn MP3 để nghe thử ngay lập tức.
